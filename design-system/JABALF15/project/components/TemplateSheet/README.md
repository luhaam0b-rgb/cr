# TemplateSheet

⁧ورقة قالب نصي جاهز للنسخ: خطاب، بيان، محضر. شريط فيه العنوان وزر النسخ، ثم نص القالب وفيه خانات يملؤها المستعمل.⁩

## ⁧البنية⁩

```html
<div class="sheet" id="f-letter">
  <div class="sheet-bar">
    <h3 id="f-letter-t">خطاب إلى شركات المنطقة</h3>
    <button class="copy" data-copy="f-letter" id="f-letter-c" aria-labelledby="f-letter-c f-letter-t">نسخ</button>
  </div>
  <div class="sheet-body">
    <p class="small">يُرسل إلى شركات المنطقة قبل موعد التركيب بأشهر.</p>
    <p>السيد/السيدة <span class="ph">(اسم مدير المتجر)</span>،</p>
  </div>
</div>
```

⁧‎`data-copy`‎ يحمل معرّف الورقة، و‎`aria-labelledby`‎ يجمع كلمة «نسخ» وعنوان الورقة فيصير اسم الزر «نسخ خطاب إلى شركات المنطقة».⁩

## ⁧السلوك⁩

- ⁧«نسخ» ينسخ نص القالب كاملًا بخاناته، ويتبدل نص الزر إلى «نُسخ» ثم يعود.⁩
- ⁧إن تعذّر النسخ يُحدَّد النص ويكتب الزر «النص محدَّد، انسخه».⁩

## ⁧قواعد⁩

- ⁧الخانة ‎`.ph`‎ تُكتب بين قوسين وتسمّي ما يُملأ: «(اسم المتجر)». لونها ‎`aurora`‎ على تعبئتها الخفيفة.⁩
- ⁧السطر الأول ‎`.small`‎ يقول متى يُستعمل القالب ولمن.⁩
- ⁧الورقة على ‎`surface-2`‎ لتتميز عن بطاقات الشرح.⁩
- ⁧قالب مترجَم عن نموذج قانوني أجنبي يُذكر ذلك في أوله، ومعه أن استعماله محليًا يحتاج صياغة قانونية محلية.⁩
