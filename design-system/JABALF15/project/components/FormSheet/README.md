# FormSheet

⁧نموذج ورقي معروض على الشاشة: أسئلة مرقَّمة في خانات، ولكل سؤال خياراته بمربّعات فارغة. يُعرض ليُقرأ ويُنقل، ولا يُملأ على الصفحة.⁩

## ⁧البنية⁩

```html
<div class="form">
  <div class="q"><span class="qn">1</span><b>التاريخ:</b></div>
  <div class="q"><span class="qn">6</span><b>نوع المسكن:</b>
    <div class="opts"><span>أسرة واحدة</span><span>شقة</span></div>
  </div>
  <div class="q"><span class="qn">8</span><b>كم منبّه دخان كان في المنزل؟</b>
    <span class="small">إذا كان صفرًا فانتقل إلى السؤال 16.</span>
    <div class="opts"><span>صفر</span><span>واحد</span></div>
  </div>
</div>
```

## ⁧قواعد⁩

- ⁧رقم السؤال ‎`.qn`‎ كما في النموذج الأصلي، ولو لم تُعرض الأسئلة كلها.⁩
- ⁧المربّع الفارغ أمام كل خيار يولّده النمط؛ لا يُكتب في النص.⁩
- ⁧تعليمات التخطّي داخل ‎`.small`‎ تحت نص السؤال.⁩
- ⁧ما يُملأ خطًّا يُكتب فراغه شرطات سفلية: «العدد ____».⁩
- ⁧النموذج المطلوب ملؤه على الشاشة يُبنى بحقول حقيقية لها ‎`label`‎، وليس بهذا المكوّن.⁩
