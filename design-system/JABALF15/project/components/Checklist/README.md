# Checklist

⁧قائمة تحقق لجولة أو فحص: جدول فيه رقم البند ونصه، وخانة فارغة لكل جواب، وعمود للتعليق. تُعرض على الشاشة وتُطبع لتُملأ باليد.⁩

## ⁧البنية⁩

```html
<div class="tw"><table class="keep check">
  <thead><tr>
    <th scope="col" class="ctr">م</th><th scope="col">بند التحقق</th>
    <th scope="col" class="ctr">نعم</th><th scope="col" class="ctr">لا</th><th scope="col" class="ctr">غير مطابق</th>
    <th scope="col">تعليقات</th>
  </tr></thead>
  <tbody>
    <tr><th scope="row" class="ctr">1</th><td>الأرضيات نظيفة وجافة …</td>
        <td class="box"></td><td class="box"></td><td class="box"></td><td></td></tr>
  </tbody>
</table></div>
```

## ⁧ما يقدّمه المستعمل⁩

- ⁧أعمدة الجواب وأسماؤها كما في النموذج المعتمد لدى الجهة. المثال ينقل أعمدة «نموذج تدريب جولات السلامة»: نعم، لا، غير مطابق.⁩
- ⁧سطر تحت الجدول يعرّف كل جواب ومتى يلزم التعليق.⁩
- ⁧عنوان ‎`h2`‎ لكل فئة بنود، وجدول لكل فئة.⁩

## ⁧قواعد⁩

- ⁧البند شرط واحد يُرى أو يُقاس. ما جمع شرطين يُقسم بندين.⁩
- ⁧الترقيم متصل عبر الفئات، حتى يُشار إلى البند برقمه وحده.⁩
- ⁧‎`keep`‎ يُبقي الجدول شبكةً على الجوال ويمرَّر أفقيًا، لأن الخانات لا تُقرأ متراصّة.⁩
- ⁧المربّع يولّده النمط في خلايا ‎`td.box`‎. للملء على الشاشة تُبنى الخلايا أزرار اختيار حقيقية لها أسماء.⁩
