# Prose

⁧نص القراءة: الفقرة الافتتاحية، الفقرة، القائمة، النص الثانوي، وما يدخل السطر من لاتيني وأرقام وروابط.⁩

## ⁧الأصناف⁩

| ⁧الصنف⁩ | ⁧الاستعمال⁩ |
| --- | --- |
| `.lead` | ⁧الفقرة الأولى في التبويب، بحجم 1.08rem.⁩ |
| `p` | ⁧نص القراءة. عرضه لا يتجاوز ‎`measure`‎ (72 حرفًا).⁩ |
| ⁧‎`.small`‎ أو ‎`small`‎⁩ | ⁧نص ثانوي بلون ‎`muted`‎: مثال، تنبيه قصير، مصدر الفقرة.⁩ |
| `.en` | ⁧المقابل الإنجليزي للمصطلح بجواره، أصغر قليلًا وبلون ‎`muted`‎.⁩ |
| `.lt` | ⁧مقطع لاتيني داخل الجملة بلون النص نفسه: اسم وثيقة، اختصار.⁩ |
| `.mono` | ⁧أرقام وحسابات ورموز وأسماء ملفات، بخط ‎`mono`‎ ومن اليسار إلى اليمين.⁩ |
| `b` | ⁧التشديد بوزن 600. لا خط مائل في النظام.⁩ |

## ⁧قواعد⁩

- ⁧كل مقطع لاتيني يحمل ‎`lang="en"`‎ (أو لغته)، حتى ينطقه قارئ الشاشة بقواعد لغته.⁩
- ⁧المقطع اللاتيني الذي يبدأ برقم يدخل كله في ‎`.lt`‎، رقمه معه: «5 Whys» خارج ‎`.lt`‎ تُرسم «Whys 5».⁩
- ⁧المصطلح العربي أولًا، والإنجليزي بجواره داخل ‎`.en`‎ عند أول ورود فقط.⁩
- ⁧الروابط مسطَّرة دائمًا وبلون ‎`aurora`‎، وعند المرور ‎`gold`‎. اللون وحده لا يكفي لتمييز الرابط.⁩
- ⁧علامات القوائم بلون ‎`gold`‎. القائمة النقطية ‎`disc`‎ والمرقمة ‎`decimal`‎، ويُعلن ذلك صراحة لأن أوراق الأنماط الأساسية في بعض الأطر تحذفه.⁩
- ⁧ارتفاع السطر 1.85، والمحاذاة لليمين بلا ضبط للحافتين.⁩
- ⁧لا نص عربي دون 0.875rem.⁩
