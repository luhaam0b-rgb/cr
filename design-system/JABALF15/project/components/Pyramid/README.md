# Pyramid

⁧خمس درجات مرتَّبة من الأقوى إلى الأضعف، كل درجة تدخل خطوة عن التي فوقها، ولونها يسير من ‎`emerald`‎ إلى ‎`gold`‎ إلى ‎`alarm`‎. بُني لتسلسل ضوابط المخاطر.⁩

## ⁧البنية⁩

```html
<ol class="pyr">
  <li class="l1"><b>الإزالة</b><span>التدابير الرامية إلى إزالة المخاطر …</span></li>
  <li class="l2"><b>الاستبدال</b><span>…</span></li>
  <li class="l3"><b>الضوابط الهندسية</b><span>…</span></li>
  <li class="l4"><b>الضوابط الإدارية</b><span>…</span></li>
  <li class="l5"><b>معدات الحماية الشخصية</b><span>…</span></li>
</ol>
```

## ⁧قواعد⁩

- ⁧للتسلسل الذي ترتيبه ملزم وأعلاه أفضله. الدرجة الأولى ‎`l1`‎ هي الأقوى.⁩
- ⁧التدرّج اللوني يكرر ما يقوله الترتيب والإزاحة، ولا ينفرد بالمعنى.⁩
- ⁧سلّم من ثلاث درجات يأخذ ‎`l1`‎ و‎`l3`‎ و‎`l5`‎.⁩
- ⁧دون 620px تُلغى الإزاحة وتبقى الدرجات بترتيبها وألوانها.⁩
