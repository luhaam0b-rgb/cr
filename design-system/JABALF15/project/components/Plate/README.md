# Plate

⁧إطار الصورة: الرسم المصدري على ورقة بيضاء فوق سطح الصفحة، وفوقه شريط فيه رقم الصورة وعنوانها ومفتاح لغة التسميات وزر التكبير، وتحته تعليق.⁩

## ⁧البنية⁩

```html
<figure class="plate" id="fig-f01">
  <div class="plate-bar">
    <span class="plate-no">الصورة 1</span>
    <span class="plate-title">الصورة الكاملة لنظام إنذار الحريق</span>
    <span class="seg" role="group" aria-label="لغة التسميات: الصورة 1، الصورة الكاملة لنظام إنذار الحريق">
      <button type="button" data-mode="ar" aria-pressed="true">عربي</button>
      <button type="button" data-mode="orig" aria-pressed="false">الأصل</button>
    </span>
    <button type="button" class="zbtn" aria-label="تكبير: الصورة 1، الصورة الكاملة لنظام إنذار الحريق">تكبير</button>
  </div>
  <div class="paper">
    <svg class="figsvg" viewBox="…" role="img" aria-label="…">
      <!-- الرسم المصدري بتسمياته -->
      <g class="ov"> <!-- غطاء أبيض ثم التسمية العربية، لكل تسمية في موضعها --> </g>
    </svg>
  </div>
  <ul class="sr-only" aria-label="تسميات الصورة 1"><li>…</li></ul>
  <figcaption>…</figcaption>
</figure>
```

⁧نافذة التكبير عنصر واحد في آخر الصفحة تتشاركه كل الصور:⁩

```html
<div id="zoom" hidden role="dialog" aria-modal="true" aria-label="تكبير الصورة">
  <div class="zbar"><span class="ztitle"></span><button type="button">إغلاق</button></div>
  <div class="zbody" tabindex="0" role="group" aria-label="الصورة المكبّرة، تُمرَّر بالأسهم"><div class="zsheet"></div></div>
</div>
```

## ⁧ما يقدّمه المستعمل⁩

- ⁧الرسم ‎`svg.figsvg`‎ بتسمياته الأصلية، ومجموعة ‎`g.ov`‎ فيها لكل تسمية غطاء بلون ‎`paper`‎ ونص عربي بلون ‎`paper-ink`‎ في الموضع نفسه.⁩
- ⁧رقم الصورة وعنوانها، ويتكرران في اسم المفتاح واسم زر التكبير حتى يتميز كل زر عند قارئ الشاشة.⁩
- ⁧قائمة ‎`.sr-only`‎ بالتسميات العربية كلها، لأن ‎`role="img"`‎ يحجب نصوص الرسم.⁩
- ⁧التعليق: ما يُرى في الصورة، أو كيف تُقرأ.⁩

## ⁧الأشكال⁩

| ⁧الصنف⁩ | ⁧الاستعمال⁩ |
| --- | --- |
| `.plate` | ⁧صورة بعرض العمود.⁩ |
| `.plate.narrow` | ⁧رسم صغير: لا يتجاوز 640px ويتوسّط.⁩ |
| `.plate.wide` | ⁧يمتد على عمودي الشبكة ‎`.pair`‎.⁩ |
| `.plate.crop` | ⁧مقتطع من صورة سابقة: بلا مفتاح ولا تكبير، ورقمه «من الصورة 1».⁩ |
| `.plate.board` | ⁧لوحة مكتملة تملأ الإطار بلا حشو.⁩ |
| `.pair` | ⁧صورتان متجاورتان تنزلان عمودًا على الجوال.⁩ |

## ⁧السلوك⁩

- ⁧«عربي / الأصل» يُظهر مجموعة ‎`.ov`‎ أو يخفيها، و‎`aria-pressed`‎ يحمل الحالة.⁩
- ⁧«تكبير» أو الضغط على الورقة يفتح النافذة والتركيز على «إغلاق». ما خلف النافذة يصير ‎`inert`‎. Esc يغلقها ويعيد التركيز إلى الزر الذي فتحها.⁩
- ⁧عرض الورقة المكبّرة يُحسب حتى لا تنزل أصغر تسمية عن 11px، بحدّ أقصى 1600px، وتمرَّر في الاتجاهين.⁩

## ⁧قواعد⁩

- ⁧الورقة بيضاء في السمتين. الرسم المصدري لا يُعاد تلوينه.⁩
- ⁧لون التسمية العربية يطابق لون أصلها، ويُغمَّق حتى يبلغ 4.5:1 على غطائه. ألوان إطارات الرسم تبقى كما هي.⁩
- ⁧النص يُبنى حيًّا فوق الرسم، ولا تُدرج صورة نقطية تحمل النص: النص المرسوم لا يُبحث فيه ولا يكبر ولا يُقرأ آليًّا.⁩
- ⁧نافذة التكبير داكنة في السمتين، وألوانها ثابتة لا تتبع السمة.⁩
