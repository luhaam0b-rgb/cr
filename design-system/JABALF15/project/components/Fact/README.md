# Fact

⁧جملة واحدة قائمة بنفسها، أمامها معيّن ذهبي. للحقائق والأرقام المنقولة عن المصدر التي تُقرأ واحدة واحدة.⁩

## ⁧البنية⁩

```html
<div class="stack-sm">
  <div class="fact"><span>في كل سنة تقع ثلاث من كل خمس وفيات …</span></div>
  <div class="fact"><span>خطر الوفاة في حريق منزلي مبلَّغ عنه ينخفض إلى النصف …</span></div>
</div>
```

## ⁧قواعد⁩

- ⁧جملة واحدة لكل حقيقة، بنصها ورقمها كما في المصدر. المصدر يُذكر في الفقرة التي تسبق المجموعة أو في التذييل.⁩
- ⁧تُجمع الحقائق في ‎`.stack-sm`‎. حقيقة منفردة تُكتب فقرة عادية.⁩
- ⁧المعيّن علامة النظام للحقائق، والقرص الذهبي للخطوات، والنقطة للقوائم. لا تُستبدل برموز تعبيرية.⁩
