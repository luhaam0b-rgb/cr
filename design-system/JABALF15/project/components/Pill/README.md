# Pill

⁧شارة صغيرة تصنّف العنصر الذي بجوارها: نوع الوثيقة، مجالها، عدد إدخالاتها.⁩

## ⁧البنية⁩

```html
<span class="pill C">كود</span>
<span class="pill S">معيار</span>
<span class="pill R">ممارسة موصى بها</span>
<span class="pill G">دليل</span>
<span class="pill">الكهرباء والطاقة</span>
```

## ⁧الأصناف⁩

| ⁧الصنف⁩ | ⁧اللون⁩ | ⁧المعنى⁩ |
| --- | --- | --- |
| `.pill` | ⁧‎`muted`‎ وحدّ ‎`edge`‎⁩ | ⁧وصف محايد: المجال، العدد، نوع النسخة.⁩ |
| `.pill.C` | `gold` | ⁧كود.⁩ |
| `.pill.S` | `aurora` | ⁧معيار.⁩ |
| `.pill.R` | `plasma` | ⁧ممارسة موصى بها.⁩ |
| `.pill.G` | `emerald` | ⁧دليل.⁩ |

## ⁧قواعد⁩

- ⁧الألوان الأربعة مربوطة بأنواع الوثائق الأربعة. مرجع يصنّف شيئًا آخر يعرّف مفتاحه في قسم «كيف يُقرأ» قبل أن يستعملها.⁩
- ⁧النص من كلمة إلى ثلاث، بحجم 0.875rem وهو أصغر حجم لنص عربي في النظام.⁩
- ⁧الشارة وصف لا زر: لا تُضغط ولا يتغير شكلها عند المرور.⁩
