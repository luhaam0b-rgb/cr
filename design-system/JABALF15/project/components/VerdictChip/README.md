# VerdictChip

⁧شارة تحمل نتيجة مطابقة معلومة على مصدرها: مطابق، توضيح، لم يوثَّق.⁩

## ⁧البنية⁩

```html
<span class="vd ok">مطابق</span>
<span class="vd fix">توضيح</span>
<span class="vd un">لم يوثَّق</span>
```

## ⁧الأحكام⁩

| ⁧الصنف⁩ | ⁧اللون⁩ | ⁧متى⁩ |
| --- | --- | --- |
| `.vd.ok` | `emerald` | ⁧المعلومة وُجدت في المصدر بنصها أو برقمها.⁩ |
| `.vd.fix` | `gold` | ⁧وُجدت، وتحتاج قيدًا أو تصحيحًا يُكتب في عمود المصدر.⁩ |
| `.vd.un` | `plasma` | ⁧لم يُعثر لها على مصدر. تبقى معروضة ومعلَّمة.⁩ |

## ⁧قواعد⁩

- ⁧كل حكم يقابله في الصف نفسه المصدر الذي طوبق عليه. حكم بلا مصدر لا يُكتب.⁩
- ⁧«لم يوثَّق» ليست «خطأ»: المعلومة لم تُنفَ، وإنما لم يثبت سندها.⁩
- ⁧الكلمة هي الحكم، واللون يعين على المسح بالعين فقط.⁩
