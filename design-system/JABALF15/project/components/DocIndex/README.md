# DocIndex

⁧بند في فهرس الوثائق: الرمز في عمود، وبجواره العنوان العربي، فالأصلي، فشارات الصنف، فسنوات الإصدار، فما يُلاحظ على البند.⁩

## ⁧البنية⁩

```html
<div class="docs" id="docs">
  <article class="doc" data-g="A" data-t="C" data-k="base" data-n="1" data-c="1" data-m="1">
    <div class="code" lang="en">NFPA 1</div>
    <div class="body">
      <div class="ar">كود الحريق</div>
      <div class="or" lang="en">Fire Code</div>
      <div class="meta"><span class="pill C">كود</span><span class="pill">10 إدخالات · <span class="mono">1997–2027</span></span></div>
      <div class="yrs"><i class="new">2027</i><i>2024</i><i>2021</i></div>
      <div class="var"><span class="vs">كما ورد في القائمة: قانون الحريق</span></div>
      <div class="memo">يحدد مع NFPA 101 متى يلزم وجود نظام إنذار …</div>
    </div>
  </article>
</div>
```

## ⁧ما يقدّمه المستعمل⁩

- ⁧خصائص الترشيح على كل بند: ‎`data-g`‎ المجال، ‎`data-t`‎ النوع، ‎`data-k`‎ نوع النسخة، ‎`data-n`‎ الرقم، ‎`data-c`‎ الرمز بأحرف صغيرة، و‎`data-m`‎ إن كان للبند ملاحظة.⁩
- ⁧العنوان الأصلي ‎`.or`‎ بلغته ومعه ‎`lang`‎.⁩
- ⁧السنوات من الأحدث إلى الأقدم. الأحدث ‎`class="new"`‎، وسنة المراجعة ‎`class="r"`‎، وإن اجتمعتا ‎`class="r new"`‎.⁩

## ⁧أجزاء البند⁩

| ⁧الجزء⁩ | ⁧المعنى⁩ |
| --- | --- |
| `.yrs i.new` | ⁧أحدث إصدار: تعبئة ‎`aurora`‎ ونص ‎`bg`‎.⁩ |
| `.yrs i.r` | ⁧إصدار مراجعة قادم: نص وحدّ ‎`plasma`‎.⁩ |
| `.yrs i.r.new` | ⁧مراجعة وهي الأحدث: تعبئة ‎`plasma`‎ ونص ‎`bg`‎.⁩ |
| `.var` | ⁧اختلاف العنوان بين الإصدارات، أو صيغته كما وردت في القائمة المنسوخة.⁩ |
| `.memo` | ⁧ملاحظة المحرر على البند: صلة بباقي المرجع، أو تنبيه على تاريخه.⁩ |

## ⁧قواعد⁩

- ⁧العنوان العربي للوثيقة ترجمة غير رسمية، والأصلي يبقى ظاهرًا تحته دائمًا.⁩
- ⁧ما في القائمة المنسوخة يُعرض «كما ورد» ولو كان خطأ، والتصحيح يُكتب بجواره لا مكانه.⁩
- ⁧دون 600px ينزل الرمز فوق العنوان.⁩
