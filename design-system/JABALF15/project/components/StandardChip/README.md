# StandardChip

⁧رمز وثيقة مرجعية داخل النص على هيئة زر: يفتح الوثيقة في الفهرس ويرشّح القائمة برقمها.⁩

## ⁧البنية⁩

```html
<button class="std" data-std="NFPA 72" lang="en">NFPA 72</button>
```

⁧مع سنوات الوثيقة بجواره:⁩

```html
<span class="cx"><button class="std" data-std="NFPA 402" lang="en">NFPA 402</button><span class="small mono">1996–2019</span></span>
```

## ⁧السلوك⁩

- ⁧الضغط يفتح تبويب الفهرس، ويكتب الرمز في حقل البحث، وينقل التركيز إلى القائمة.⁩
- ⁧عند المرور يُعبَّأ بلون ‎`gold`‎ ونصه ‎`bg`‎.⁩

## ⁧قواعد⁩

- ⁧نص الزر هو رمز الوثيقة كما تكتبه جهتها، بخط ‎`mono`‎ ومع ‎`lang="en"`‎.⁩
- ⁧لا يُكتب رمز وثيقة لم تُقرأ أو لم يُتحقق من أنها تحكم الموضوع.⁩
- ⁧إن لم يكن في المرجع فهرس، يُكتب الرمز داخل ‎`.mono`‎ نصًّا لا زرًّا.⁩
- ⁧على شاشات اللمس ارتفاعه 40px لأنه داخل السطر.⁩
