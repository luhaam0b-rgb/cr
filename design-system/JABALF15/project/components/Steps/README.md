# Steps

⁧خطوات مرقَّمة لإجراء أو تسلسل يحدث بترتيب ثابت. الرقم في قرص ذهبي والنص بجواره.⁩

## ⁧البنية⁩

```html
<ol class="steps">
  <li><div><b>الوضع الطبيعي:</b> تيار مراقبة صغير يخرج من الوحدة …</div></li>
  <li><div><b>الإنذار:</b> جهاز يغلق تماسه …</div></li>
</ol>
```

⁧نص كل خطوة داخل ‎`div`‎ واحد، لأن البند شبكة من عمودين: الرقم ثم النص.⁩

## ⁧قواعد⁩

- ⁧للترتيب الملزم فقط. ما لا ترتيب له قائمة نقطية.⁩
- ⁧الترقيم يولّده العدّاد؛ لا يُكتب الرقم في النص.⁩
- ⁧تبدأ الخطوة باسمها بخط عريض إن كان لها اسم، ثم نقطتان، ثم الشرح.⁩
