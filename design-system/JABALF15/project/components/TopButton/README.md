# TopButton

⁧زر عائم يعيد القارئ إلى أعلى الصفحة. يظهر بعد النزول 700px ويختفي فوقها.⁩

## ⁧البنية⁩

```html
<button type="button" class="top" hidden aria-label="العودة إلى أعلى الصفحة">أعلى</button>
```

## ⁧قواعد⁩

- ⁧هو العنصر الوحيد الذي يحمل ظلًّا (‎`shadow-float`‎)، لأنه الوحيد الذي يطفو فوق المحتوى.⁩
- ⁧موضعه الزاوية السفلى اليسرى، خارج مسار القراءة العربي.⁩
- ⁧لا يُطبع.⁩
