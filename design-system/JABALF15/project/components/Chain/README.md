# Chain

⁧سلسلة مراحل متتابعة تُرى كلها في نظرة: خانات متجاورة بينها سهم، في كل خانة اسم المرحلة وسطر تحته.⁩

## ⁧البنية⁩

```html
<ol class="chain">
  <li><b>إجراءات فورية</b><span lang="en">Immediate Action</span></li>
  <li><b>خطة التحقيق</b><span lang="en">Plan the Investigation</span></li>
</ol>
```

## ⁧متى تُستعمل⁩

- ⁧لمراحل عملية كاملة، من ثلاث إلى سبع، يُراد أن تُرى معًا قبل شرح كل واحدة.⁩
- ⁧إجراء تُنفَّذ خطواته واحدة واحدة له ‎`Steps`‎. ومستويات يُبنى بعضها على بعض لها ‎`Layers`‎.⁩

## ⁧قواعد⁩

- ⁧قائمة مرتَّبة ‎`ol`‎، فيُعلن قارئ الشاشة عدد المراحل وترتيبها. الرقم لا يُكتب في الاسم.⁩
- ⁧السطر الثاني قصير: المقابل الإنجليزي، أو ما تنتجه المرحلة.⁩
- ⁧السهم يتبع اتجاه الصفحة. دون 700px تنزل الخانات صفوفًا ويختفي السهم.⁩
