# Bars

⁧أشرطة أفقية تقارن أعدادًا بين فئات: اسم الفئة، ثم الشريط، ثم الرقم.⁩

## ⁧البنية⁩

```html
<div class="bars">
  <div class="bar"><span>المواد والعمليات الخطرة</span><span class="t"><i style="width:71.0%"></i></span><span class="v">44</span></div>
</div>
```

⁧عرض الشريط نسبة قيمة الفئة إلى أكبر قيمة في المجموعة.⁩

## ⁧قواعد⁩

- ⁧مرتبة من الأكبر إلى الأصغر، إلا إذا كان للفئات ترتيب طبيعي.⁩
- ⁧لون واحد لكل الأشرطة (‎`aurora`‎) على مسار ‎`surface-2`‎. اللون لا يميّز فئة عن أخرى؛ الاسم يفعل ذلك.⁩
- ⁧الرقم مكتوب دائمًا بجوار شريطه. الشريط لا يُقرأ بلا رقمه.⁩
- ⁧لمقارنة قيمة واحدة بين فئات. ما له بُعدان أو سلسلة زمنية يأخذ جدولًا.⁩
