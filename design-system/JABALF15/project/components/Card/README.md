# Card

⁧سطح يجمع فكرة واحدة: عنوان ‎`h3`‎ وتحته نصها. والشبكة تصفّ البطاقات المتناظرة.⁩

## ⁧البنية⁩

```html
<div class="grid-2">
  <div class="card"><h3>منبّه الدخان ليس كاشف الدخان</h3><p>…</p></div>
  <div class="card"><h3>البودرة الكيميائية ليست بودرة المعادن</h3><p>…</p></div>
</div>
```

⁧‎`.grid`‎ أعمدة لا تقل عن 260px (ثلاث بطاقات قصيرة في الصف)، و‎`.grid-2`‎ لا تقل عن 340px (بطاقتان). كلتاهما تنزل إلى عمود واحد على الجوال دون استعلام عن العرض.⁩

## ⁧قواعد⁩

- ⁧البطاقة على ‎`surface`‎ بحدّ ‎`edge`‎ وزاوية ‎`r`‎، بلا ظل.⁩
- ⁧بطاقات الصف الواحد متناظرة في نوع محتواها.⁩
- ⁧لا بطاقة داخل بطاقة. ما احتاج تقسيمًا داخليًا يأخذ ‎`h4`‎ أو قائمة.⁩
- ⁧المحتوى المتصل الذي يُقرأ بالتسلسل يبقى فقرات في القسم.⁩
