# Table

⁧الجدول داخل إطار ‎`.tw`‎: رأس ذهبي على ‎`surface-2`‎، وخطوط أفقية فقط، وعنوان لكل صف.⁩

## ⁧البنية⁩

```html
<div class="tw"><table>
  <thead><tr><th scope="col">الموضوع</th><th scope="col">في الدليل</th><th scope="col">الوثيقة المرجعية</th></tr></thead>
  <tbody>
    <tr><th scope="row"><b>مصدر الطاقة</b></th><td>…</td><td><button class="std" data-std="NFPA 72" lang="en">NFPA 72</button></td></tr>
  </tbody>
</table></div>
```

## ⁧أصناف الخلايا⁩

| ⁧الصنف⁩ | ⁧الاستعمال⁩ |
| --- | --- |
| `th[scope="row"]` | ⁧أول خلية في الصف: عنوانه.⁩ |
| `.num` | ⁧خلية أرقام: خط ‎`mono`‎، محاذاة لليسار، أرقام متساوية العرض. رأس عمودها يأخذ الصنف نفسه للمحاذاة ويبقى بخط العناوين.⁩ |
| `.lat` | ⁧خلية نص لاتيني: من اليسار إلى اليمين وبلون ‎`muted`‎، ومعها ‎`lang`‎.⁩ |
| `.ctr` | ⁧خلية موسَّطة: درجة، وحدة، خانة.⁩ |
| `tfoot` | ⁧صف الإجمالي على ‎`surface-2`‎ وبوزن 600.⁩ |

## ⁧السلوك على الجوال⁩

- ⁧دون 680px يتحول كل صف إلى كتلة: عنوان الصف أولًا، ثم كل خلية تحت اسم عمودها. السكربت ينسخ أسماء الأعمدة إلى الخلايا ويضيف الصنف ‎`tstack`‎.⁩
- ⁧جدول الأرقام الذي لا يُقرأ إلا شبكةً يأخذ الصنف ‎`keep`‎: يبقى جدولًا ويمرَّر أفقيًا داخل إطاره.⁩
- ⁧الإطار الذي يمرَّر يصير محطة تركيز باسم مقروء، حتى يمرَّر بلوحة المفاتيح.⁩

## ⁧قواعد⁩

- ⁧‎`scope="col"`‎ لكل رأس عمود و‎`th scope="row"`‎ لعنوان كل صف.⁩
- ⁧الخلية الفارغة تُكتب شرطة طويلة «—» إن كان فراغها معلومة، وتُترك فارغة في صف الإجمالي.⁩
- ⁧لا خطوط رأسية ولا تظليل متناوب للصفوف.⁩
