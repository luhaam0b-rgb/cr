# Section

⁧القسم وحدة القراءة داخل التبويب: رأس فيه وسم صغير وعنوان ‎`h2`‎، ثم المحتوى. والقسم الفرعي ‎`.sub`‎ يبدأ بعنوان ‎`h3`‎.⁩

## ⁧البنية⁩

```html
<div class="sec" id="map-cross">
  <header><span class="tag" lang="en">CROSS-REFERENCES</span><h2>أين يلتقي المحتوى</h2></header>
  <p>…</p>
  <div class="sub" id="map-ext">
    <h3>أين تلتقي الطفايات بباقي المرجع</h3>
    …
  </div>
</div>
```

⁧للأقسام المرقَّمة يحل ‎`.stepno`‎ محل الوسم: ‎`<span class="stepno">الخطوة 3</span>`‎.⁩

## ⁧ما يقدّمه المستعمل⁩

- ⁧معرّف ‎`id`‎ لكل قسم يُربط إليه من قائمة المحتويات ومن الروابط الداخلية.⁩
- ⁧الوسم ‎`.tag`‎: كلمة أو كلمتان لاتينيتان بأحرف كبيرة تسمّيان موضوع القسم، مع ‎`lang="en"`‎. يُحذف الوسم إن لم يكن للقسم اسم لاتيني متداول.⁩

## ⁧قواعد⁩

- ⁧تسلسل العناوين: ‎`h2`‎ للقسم، ‎`h3`‎ للقسم الفرعي والبطاقة، ‎`h4`‎ لما داخل البطاقة. لا قفز من ‎`h2`‎ إلى ‎`h4`‎.⁩
- ⁧المسافات بين عناصر القسم تصنعها فجوة الحاوية (‎`gap-sec`‎ و‎`gap-sub`‎)؛ لا تُضاف هوامش للعناصر.⁩
- ⁧بين قسم وقسم داخل التبويب ‎`gap-panel`‎.⁩
- ⁧النقطة الوسطى بين رقم وعنوان، في ‎`h2`‎ إلى ‎`h4`‎ وفي اسم المرحلة داخل ‎`Chain`‎، تُكتب داخل ‎`span.dot`‎. خط العناوين يرسمها بحجم الصفر العربي، فتُقرأ «٤ · تحليل» «٤٠ تحليل».⁩
