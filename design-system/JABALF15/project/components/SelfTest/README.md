# SelfTest

⁧سؤال يُفتح على جوابه. للمراجعة قبل اختبار: يقرأ القارئ السؤال، يجيب في نفسه، ثم يفتح.⁩

## ⁧البنية⁩

```html
<div data-quiz>
  <button type="button" class="go" data-quiz-all aria-pressed="false">فتح كل الإجابات</button>
  <details class="quiz">
    <summary>ما الفرق النظامي بين «الحادث» و«الحادث الوشيك»؟</summary>
    <div class="ans"><b>الحادث</b> حدث غير مرغوب فيه <b>يؤدي</b> إلى …</div>
  </details>
</div>
```

## ⁧السلوك⁩

- ⁧عنصر ‎`details`‎ أصلي: يُفتح بالضغط وبمفتاحي Enter والمسافة، ويُعلن حالته لقارئ الشاشة.⁩
- ⁧السؤال المفتوح يتحول عنوانه إلى ‎`aurora`‎.⁩
- ⁧زر ‎`data-quiz-all`‎ يفتح كل أسئلة مجموعته ‎`data-quiz`‎ ثم يغلقها، ونصه يتبدل بين «فتح كل الإجابات» و«إغلاق كل الإجابات».⁩
- ⁧عند الطباعة تُفتح الإجابات كلها.⁩

## ⁧قواعد⁩

- ⁧الجواب يبدأ بالحكم بخط عريض («نعم.») ثم سنده: المادة أو البند بنصه ورقمه.⁩
- ⁧لا يُكتب سؤال لم يرد جوابه في المصدر المعتمد.⁩
- ⁧علامة الاستفهام الذهبية يولّدها النمط أمام السؤال، وتتدلّى عن أول السطر فلا تدخل في التفافه.⁩
- ⁧السؤال نص متصل: المصطلح اللاتيني داخله يأخذ ‎`span.lt`‎ كما في سائر النص.⁩
