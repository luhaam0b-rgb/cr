# Masthead

⁧ترويسة الصفحة: سطر لاتيني قصير، ثم العنوان، ثم جملة تقول ما في المرجع، ثم سطر الإعداد، ثم العدّ. تظهر مرة واحدة أعلى الصفحة، فوق شريط التبويبات.⁩

## ⁧البنية⁩

```html
<header class="mast"><div class="wrap">
  <span class="kicker" lang="en">FIRE ALARM · NFPA · AR</span>
  <h1>مرجع إنذار الحريق <em>المعرّب</em></h1>
  <p>جملة واحدة تعدّد ما يحويه المرجع.</p>
  <p class="byline"><span>إعداد وتجميع … | <span class="lt" lang="en">JABALF15</span></span>
     <a href="https://www.jabalf15.com"><span lang="en">www.jabalf15.com</span></a></p>
  <div class="tally"><span><b>15</b>صورة بتسميات عربية</span> …</div>
</div></header>
```

## ⁧ما يقدّمه المستعمل⁩

- ⁧السطر اللاتيني ‎`.kicker`‎: كلمات مفتاحية بأحرف كبيرة تفصلها نقطة وسطى، ومعه ‎`lang="en"`‎.⁩
- ⁧إن كان السطر عربيًا، اسم جهة أو برنامج، فمعه ‎`lang="ar"`‎: يُرسم بخط النص بوزن 600 وقياس 0.875rem بلا تباعد بين الأحرف.⁩
- ⁧سطر الإعداد ‎`.byline`‎ بلا رابط: عناصر ‎`span`‎ متجاورة، والاسم في كل منها داخل ‎`b`‎.⁩
- ⁧العنوان ‎`h1`‎، وكلمة واحدة منه داخل ‎`em`‎ تأخذ لون ‎`gold`‎.⁩
- ⁧جملة الوصف: ما في المرجع بأعداده، لا وصفًا لجودته.⁩
- ⁧العدّ ‎`.tally`‎: أرقام مأخوذة من المحتوى نفسه. الرقم داخل ‎`b`‎ والتسمية بعده مباشرة.⁩

## ⁧قواعد⁩

- ⁧عنوان ‎`h1`‎ واحد في الصفحة.⁩
- ⁧الوهجان خلف الترويسة (‎`gold`‎ بنسبة 16% و‎`aurora`‎ بنسبة 14%) هما التدرّج اللوني الوحيد في النظام. لا يُكرَّر في مكوّن آخر.⁩
- ⁧رابط سطر الإعداد بلا تسطير وله خط سفلي رفيع بلون ‎`aurora`‎؛ كل رابط غيره في النص مسطَّر.⁩
