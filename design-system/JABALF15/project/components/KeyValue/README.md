# KeyValue

## ⁧البنية⁩

```html
<dl class="kv">
  <dt>وضع الصمامات</dt><dd>مفتاح على صمام التحكم يرسل إشارة …</dd>
  <dt class="mono" lang="en">-ES · -PT</dt><dd>نسخة لغة: إسبانية أو برتغالية.</dd>

```

## ⁧قواعد⁩

- ⁧الاسم قصير: من كلمة إلى أربع. إن طال فالموضع جدول.⁩
- ⁧يصح أن يكون الاسم شارة ‎`.pill`‎ أو رمزًا بخط ‎`mono`‎.⁩
- ⁧دون 620px يتراصّ العمودان: الاسم فوق شرحه.⁩
- ⁧ثلاثة أعمدة فأكثر تعني جدولًا، لا قائمة تعريف.⁩
