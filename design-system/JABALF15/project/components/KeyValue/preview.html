وضع الصمامات
مفتاح على صمام التحكم يرسل إشارة حين يتحرك الصمام عن وضعه الطبيعي، ومعناها في الغالب أنه أُغلق، وإشارة مميزة أخرى حين يعود. الغاية أن يبقى ماء أنظمة الإطفاء متاحًا.
درجة الحرارة
إشارة حين تهبط حرارة الفراغ عن 40°ف (4°م)، وأخرى حين تعود فوقها. الغاية أن تبقى أنظمة الإطفاء المائية فوق درجة التجمد.
كود Code
معيار واسع يجمع أحكامًا تغطي موضوعًا عريضًا، أو يصلح للاعتماد قانونًا بمفرده.
