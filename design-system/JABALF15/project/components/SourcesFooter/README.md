# SourcesFooter

⁧تذييل الصفحة: سطر الإعداد، ثم قائمة المصادر، ثم حدود المرجع. كل مرجع ينتهي به.⁩

## ⁧البنية⁩

```html
<footer class="src"><div class="wrap stack">
  <p class="byline"><span>إعداد وتجميع … | <span class="lt" lang="en">JABALF15</span></span><a href="…">…</a></p>
  <h3>المصادر</h3>
  <ul>
    <li>اسم المصدر وتاريخه: <a href="…">نسخة PDF</a>. منه كذا وكذا.</li>
  </ul>
  <p>النصوص الملزمة هي نصوص الوثائق الأصلية …</p>
</div></footer>
```

## ⁧ما يقدّمه المستعمل⁩

- ⁧لكل مصدر: اسمه كما هو، تاريخه، رابطه المباشر، وجملة تقول ما أُخذ منه تحديدًا.⁩
- ⁧المرفقات التي بُني منها المرجع تُذكر أولًا بأسمائها وأعدادها.⁩

## ⁧قواعد⁩

- ⁧لا يُذكر مصدر لم يُقرأ، ولا رقم مرجع لم يُتحقق منه.⁩
- ⁧اسم الملف اللاتيني داخل ‎`.mono`‎ حتى ينكسر على الشاشة الضيقة ولا يوسّع الصفحة.⁩
- ⁧نص الرابط يسمّي وجهته: «نسخة PDF»، «المقال»، لا «هنا».⁩
