# Spotlight

⁧بطاقة لمثال ميداني أو تجربة منقولة: تسمية صغيرة بنقطة، ثم عنوان، ثم الحكاية، ثم اقتباس أصحابها.⁩

## ⁧البنية⁩

```html
<div class="spot">
  <span class="lbl">مفاتيح النجاح</span>
  <h3>بناء العلاقة — كولومبوس، أوهايو</h3>
  <p>…</p>
  <blockquote>«…»</blockquote>
</div>
```

## ⁧قواعد⁩

- ⁧للمحتوى المنقول عن تجربة حقيقية مسمّاة بمكانها أو صاحبها، لا للشرح.⁩
- ⁧الاقتباس بين علامتي التنصيص العربيتين «»، بنصه كما في المصدر.⁩
- ⁧العنوان ‎`h3`‎، والتسمية تصنّف المثال بعبارة ثابتة تتكرر في المرجع كله.⁩
