# Layers

⁧خريطة مستويات مرتَّبة، كل مستوى يُبنى على الذي قبله: رقم في مربّع ملوّن، ثم العنوان وجملته، ثم زر يفتح بابه.⁩

## ⁧البنية⁩

```html
<div class="layers">
  <div class="layer"><div class="ico">1</div><div>
    <h3>المسكن: منبّه دخان مستقل</h3>
    <p>…</p>
    <button class="go" data-go="smoke">إلى برنامج منبّهات الدخان</button>
  </div></div>
</div>
```

⁧‎`data-go`‎ يحمل اسم التبويب المقصود. بعد الضغط ينتقل التركيز إلى ذلك التبويب.⁩

## ⁧قواعد⁩

- ⁧حتى أربعة مستويات، وألوان مربّعاتها بالترتيب: ‎`aurora`‎ ثم ‎`gold`‎ ثم ‎`emerald`‎ ثم ‎`plasma`‎، والرقم بلون ‎`bg`‎.⁩
- ⁧اللون يميّز المستويات بصريًا ولا يحمل معنى؛ المعنى في الرقم والعنوان.⁩
- ⁧زر ‎`.go`‎ نصه يبدأ بـ«إلى» ثم اسم الوجهة. يصلح وحده خارج الخريطة لأي انتقال إلى باب آخر.⁩
