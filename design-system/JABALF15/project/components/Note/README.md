# Note

⁧ملاحظة بين فقرات القسم. أربع درجات: هامش، قاعدة، تعريف، تحذير.⁩

## ⁧الدرجات⁩

| ⁧الصنف⁩ | ⁧الإطار⁩ | ⁧الاستعمال⁩ |
| --- | --- | --- |
| `.note` | ⁧متقطع بلون ‎`edge`‎، ونص ‎`muted`‎⁩ | ⁧معلومة جانبية يصح تجاوزها.⁩ |
| `.note.gold` | ⁧متصل مائل إلى ‎`gold`‎، ونص ‎`ink`‎⁩ | ⁧قاعدة أو معلومة يجب ألا تفوت القارئ.⁩ |
| `.note.aurora` | ⁧متصل مائل إلى ‎`aurora`‎⁩ | ⁧تعريف أو تمييز بين مصطلحين.⁩ |
| `.note.alarm` | ⁧متصل مائل إلى ‎`alarm`‎⁩ | ⁧تحذير: خطأ شائع أو ما لا يجوز فعله.⁩ |

## ⁧البنية⁩

```html
<div class="note gold">
  <span class="lbl">قاعدة</span>
  التسلسل <b>مُلزِم من الأعلى للأسفل</b> …
</div>
```

⁧السطر ‎`.lbl`‎ اختياري، ويأخذ لون درجته. بلا تسمية تبدأ الملاحظة بعبارة عريضة تنتهي بنقطتين.⁩

## ⁧قواعد⁩

- ⁧الدرجة تتبع طبيعة المعلومة، لا موضعها ولا الرغبة في إبرازها.⁩
- ⁧التحذير يحمل كلمته («خطأ شائع»، «تحذير»)؛ اللون الأحمر وحده لا يُعدّ تحذيرًا.⁩
- ⁧ملاحظة واحدة بعد الفقرة التي تخصها. ثلاث ملاحظات متتالية تعني أن المحتوى قسم.⁩
