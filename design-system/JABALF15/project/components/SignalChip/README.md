# SignalChip

⁧شارة لإحدى حالات نظام الإنذار الثلاث: إنذار، إشراف، عطل. نقطة ملوّنة وكلمة وحدّ بلون الحالة.⁩

## ⁧البنية⁩

```html
<span class="sig al">إنذار</span>
<span class="sig su">إشراف</span>
<span class="sig tr">عطل</span>
```

## ⁧قواعد⁩

- ⁧ثلاث حالات لا غير، بأسمائها الثابتة: ‎`al`‎ بلون ‎`alarm`‎، و‎`su`‎ بلون ‎`superv`‎، و‎`tr`‎ بلون ‎`trouble`‎.⁩
- ⁧الكلمة ترافق اللون دائمًا. لا تُستعمل النقطة الملوّنة وحدها، لأن الأصفرين متقاربان والأحمر لا يتميز لكل قارئ.⁩
- ⁧هذه الألوان لحالات النظام وحدها. الحكم على معلومة له ‎`VerdictChip`‎، وصنف الوثيقة له ‎`Pill`‎.⁩
- ⁧تدخل السطر كما تدخله كلمة، وتتصدّر البطاقة التي تعرّف الحالة.⁩
